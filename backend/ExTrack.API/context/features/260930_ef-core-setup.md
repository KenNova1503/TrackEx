# EF Core Setup

## Overview
This document outlines the steps to set up Entity Framework (EF) Core in the ExTrack.API project. EF Core is an Object-Relational Mapper (ORM) that enables .NET developers to work with a database using .NET objects.

## Requirements
Refer to `~/claude.md` file for the prerequisites and requirements for setting up EF Core in the ExTrack.API project.
- Install EF Core NuGet packages
- Add models
- Create the DbContext (use the connection string I already specified in user secrets)
- Add Dependency Injection and Middleware
- Create the migrations and update the database
