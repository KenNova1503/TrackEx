# ExTrack UI

React 19 + Vite frontend for the Expense Tracker. Plain JavaScript (JSX), basic CSS, Fetch API.

## Getting started

```bash
npm install
npm run dev
```

The dev server runs on http://localhost:5173.

## Scripts

| Command           | Description                      |
| ----------------- | -------------------------------- |
| `npm run dev`     | Start the dev server with HMR    |
| `npm run build`   | Build for production to `dist/`  |
| `npm run preview` | Preview the production build     |
| `npm run lint`    | Run ESLint                       |

See [`CLAUDE.md`](CLAUDE.md) and the root [`CLAUDE.md`](../../CLAUDE.md) for architecture, API and design notes.
