# App Shell: Header, Layout and View Switching

## Overview
Build the page frame: a header with Dashboard / Expenses navigation, a sidebar area and a main area that shows one view at a time.

## Requirements
Refer to the root `CLAUDE.md` § 5 (views, layout, component tree) and the frontend `CLAUDE.md` § 3 (`App.jsx`) and § 4 (`Header.jsx`).
- `App.jsx` holds `currentView` (`'dashboard'` by default) and renders one view.
- `Header.jsx` with the logo and two nav buttons; the active view's button is highlighted.
- A sidebar placeholder (`<aside className="sidebar">`) for the next task.
- Placeholder `Dashboard.jsx` and `ExpensesList.jsx` that only show their heading.
- Layout CSS: sidebar beside the main content on desktop, stacked at ≤900px.

## Notes
- Use 900px for the breakpoint (root § 6), not the 768px in the frontend `CLAUDE.md` § 6 example.
- Out of scope: data fetching, the category list.
